# Privacy Policy for APK Installer

Last updated: 6 October 2026
Publisher: Rajmane

APK Installer does not collect, store or share personal information. It has no accounts, no advertising, no analytics and no purchases.

**Files.** The app reads installer files (APK, XAPK, APKS, APKM) on your device so it can show and install them. Files are not uploaded anywhere.

**Network use.** The app connects to the internet only when you ask it to download a link you typed or pasted. The Transfer and Receive features open a small web page that is reachable only on your own Wi-Fi network while the screen is open. Each session needs a random short code shown on the screen, and nothing is sent outside your network.

**Permissions.** Install packages (to install the files you choose); all files access or storage (to find installer files in Downloads and on USB drives); network (to download links and for Wi-Fi transfer); query installed apps (to show, open, back up and uninstall apps).

**Children.** The app is not directed to children and collects no data from anyone.

**Changes.** If this policy changes, the new version will be posted at the same address.
